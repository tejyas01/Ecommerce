# 🛒 E-Commerce REST API (Spring Boot)

A robust, scalable **E-Commerce REST API** built with **Spring Boot (Java 17)**, **PostgreSQL**, **JWT Authentication**, and **Docker**.  
This API enables management of users, items, and orders — providing a solid backend foundation for an e-commerce platform.

---

## 🚀 Features

✅ **User Authentication**
- Sign-up / Sign-in with JWT tokens  
- Password hashing using BCrypt

✅ **Item Management**
- Full CRUD for items  
- Category association (supports hierarchy)  
- Search & filter by name and price  

✅ **Order Management**
- Create, view, and cancel orders  
- Automatic stock updates  
- User-specific order history  

✅ **Tech Stack**
- **Backend:** Spring Boot 3.3.x  
- **Database:** PostgreSQL  
- **Security:** Spring Security + JWT  
- **Documentation:** Swagger / OpenAPI  
- **Containerization:** Docker & Docker Compose
